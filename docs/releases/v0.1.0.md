The first release of Chess Workbench: a free, open-source desktop chess database that opens your ChessBase databases (`.cbh` and ChessBase 18's `.2cbh`) on macOS, Windows and Linux, and looks and handles like ChessBase 18.

## Highlights

- **Your databases, fast.** Scroll, sort and search the whole of an 11-million-game database. Search by game data, position, pattern, annotations and medals.
- **Analysis.** Any UCI engine (Stockfish and others), several at once, with MultiPV. Blunder check, tactical and deep analysis, analysis jobs and Syzygy tablebases.
- **Openings and players.** Opening tree and reference search, player statistics and dossiers, Prepare against White/Black, crosstables, and opening, tournament and error reports.
- **Editing.** Variations, comments, symbols, arrows and coloured squares, with undo. Save, replace and delete games in `.2cbh` databases, convert `.cbh` to `.2cbh`, and import or export PGN.
- **Familiar and private.** ChessBase's ribbon, shortcuts and four themes. It works offline: no account, nothing uploaded. A database is only written when you open it for editing.

## Downloads

| System | File |
|---|---|
| macOS, Apple Silicon or Intel | `.dmg` |
| Windows 10 or 11 (x64) | `-setup.exe`, or `.msi` |
| Linux x64 | `.AppImage`, `.deb` or `.rpm` |

No engine is bundled. Add one with **Add Kibitzer** (Ctrl+K); on macOS, `brew install stockfish` installs Stockfish at `/opt/homebrew/bin/stockfish`.

## Installing: the builds are not signed yet

This release is not signed by Apple or Microsoft, so your system warns you the first time you open it.

**macOS.** Open the `.dmg` and drag **Chess Workbench** into **Applications**. On the first launch, macOS says it cannot verify the app:
1. Click **Done** (not Move to Trash).
2. Open **System Settings › Privacy & Security**, scroll down to **Security**, and click **Open Anyway** next to "Chess Workbench was blocked". Confirm with your password.

You only need to do this once. On macOS 14 and earlier, right-clicking the app and choosing **Open** also works. If macOS instead says the app "is damaged and can't be opened", it is the download quarantine, not a broken file. Run this once in Terminal, then open the app normally:

```sh
xattr -dr com.apple.quarantine "/Applications/Chess Workbench.app"
```

**Windows.** If SmartScreen shows "Windows protected your PC", click **More info › Run anyway**. The app uses Microsoft Edge WebView2, which Windows 10 and 11 already have.

**Linux.** Make the AppImage executable (`chmod +x Chess.Workbench_*.AppImage`) and run it, or install the package (`sudo apt install ./Chess.Workbench_*.deb`, or `sudo dnf install ./Chess.Workbench-*.rpm`). It needs WebKitGTK 4.1: Ubuntu 22.04, Debian 12, Fedora 36 or later.

## Known limitations

- The Windows and Linux builds are made automatically and have not yet been tried on real machines. Please report anything that goes wrong.
- Classic `.cbh` databases open read-only; the app writes ChessBase 18's `.2cbh` format only.
- Not there yet: training, repertoire databases, printing and publishing, correspondence chess, and ChessBase's online services. See the [feature checklist](https://github.com/d4nu-00/openfile/blob/main/feature_checklist.md) and [compatibility notes](https://github.com/d4nu-00/openfile/blob/main/docs/compatibility.md).
